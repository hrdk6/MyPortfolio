Selected work

Three systems, built end to end and measured.

Clinical AI platform

CareFlow AI

A full-stack clinical assistant where the LLM only ever sees data the signed-in user may access. Role checks and row-level SQL filters run before any retrieval, ML or generation, and a deterministic router plans the SQL, RAG and ML tool calls.

  • Hybrid RAG. bge-small embeddings with BM25, RRF fusion, cross-encoder reranking and citation validation.
  • Explainable risk models on 99K encounters: a calibrated Random Forest for 30-day readmission (PR-AUC 2× base rate, SHAP) and XGBoost length of stay, with patient-grouped splits and leakage ablations.
  • X-ray triage. Logistic heads on frozen ResNet-50 (ONNX) features, trained on 26K NIH ChestX-ray14 films, with class activation maps.
  • Privacy gateway. An identifier vault, regex and ONNX BERT NER pseudonymize patient data before prompts reach cloud LLMs, then restore it server-side.

Autonomous coding agent

PatchPilot

Give it a repository and a bug report and it returns a tested patch. A 9-node LangGraph state machine indexes the code, retrieves context, plans, writes a patch, tests it in a sandbox, and feeds failures back into a budget-capped repair loop.

  • Explainable retrieval. AST-based, symbol-level chunking and hybrid ranking over 7 weighted signals (semantic, lexical, import/call graph, failure trace and more), logging why each chunk entered the prompt.
  • Hardened sandbox. LLM-written code runs in Docker with no network, a non-root user, all capabilities dropped and CPU, memory, PID and time limits. A patch policy blocks CI configs, lockfiles and path traversal, and redacts secrets.
  • Benchmark harness. Model-agnostic across OpenAI, Anthropic and Ollama, reporting pass rate with Wilson 95% CIs, p50/p95 latency, tokens and cost.

Self-verifying RAG

GroundTruth

Version-aware RAG over multi-release Kubernetes docs. It checks every sentence it writes against the cited source, regenerates once when a check fails, and declines to answer when the docs don't support one.

  • Retrieval in SQL. pgvector HNSW plus BM25 implemented in SQL (matching a Python reference to 1e-9), RRF fusion, query rewriting and multi-hop decomposition.
  • Rigorous evaluation. Bootstrap 95% CIs, paired significance tests and a CI regression gate on every change. A self-audit caught 13 measurement bugs.
  • Decisions from data. Dropped cross-encoder reranking after measuring about 100× latency for no significant recall gain. Per-stage tracing, six-way failure attribution and a Next.js trace viewer.
